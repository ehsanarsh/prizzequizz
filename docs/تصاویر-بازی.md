# راهنمای تصاویر PrizzeQuizz

هر تصویری که بازی از روی فایل می‌خواند، اینجا فهرست شده است: چه اسمی بگذاری،
کجای بازی دیده می‌شود، و چه دستوری بزنی.

## قاعده‌ی کلی

بازی برای هر تصویر **سه فرمت** را به همین ترتیب امتحان می‌کند:

```
<اسم>.webp  →  <اسم>.png  →  <اسم>.jpg
```

اولی که پیدا شود همان استفاده می‌شود. پس **فرمت مهم نیست** — فقط اسم فایل مهم است.
اگر هیچ‌کدام روی سرور نباشد، بازی به‌جای عکس، ایموجی یا کاراکتر پیش‌فرض را نشان
می‌دهد و هیچ‌جا عکس شکسته دیده نمی‌شود.

همه‌ی این فایل‌ها در **ریشه‌ی وب** می‌نشینند:

```
/var/www/prizequiz/
```

اندازه‌ی پیشنهادی: تصاویر کاراکتر و مود با **پس‌زمینه‌ی شفاف (PNG یا WebP)**
بهترین نتیجه را می‌دهند.

---

## دستور کپی (الگوی ثابت)

فایل را که در `/home/ubuntu` آپلود کردی، با همین یک خط سرِ جایش بگذار:

```
sudo cp /home/ubuntu/<اسم فایل> /var/www/prizequiz/<اسم فایل>
```

بعد از کپی، کش مرورگر گوشی را یک‌بار پاک کن (یا صفحه را با refresh سخت باز کن)،
چون مرورگر عکس قبلی را نگه می‌دارد.

## ۱) کاراکتر برد و باخت — صفحه‌ی نتیجه

| اسم فایل   | کجا دیده می‌شود |
|------------|-----------------|
| `winchar`  | وسط صفحه‌ی «برنده شدی» — در **همه‌ی مودها**: دوئل، آخرین بازمانده، همه یا هیچ، لیگ |
| `losechar` | وسط صفحه‌ی «حذف شدی» — در همه‌ی مودها |

دستور برای فایلی که همین حالا فرستادی (`winchar`) — بسته به فرمتش یکی از این‌ها:

```
sudo cp /home/ubuntu/winchar.png /var/www/prizequiz/winchar.png
```

```
sudo cp /home/ubuntu/winchar.webp /var/www/prizequiz/winchar.webp
```

```
sudo cp /home/ubuntu/winchar.jpg /var/www/prizequiz/winchar.jpg
```

اگر فایل را بدون پسوند فرستاده‌ای، اول ببین چیست و بعد با پسوند درست کپی کن:

```
file /home/ubuntu/winchar
```

کاراکتر باخت هم دقیقاً به همین شکل:

```
sudo cp /home/ubuntu/losechar.png /var/www/prizequiz/losechar.png
```

> اگر قبلاً `winchar.webp` روی سرور بوده و حالا `winchar.png` می‌گذاری، **آن webp
> قدیمی جلوی png جدید را می‌گیرد** (چون webp اول امتحان می‌شود). پس اول قدیمی را
> بردار:
> ```
> sudo rm -f /var/www/prizequiz/winchar.webp
> ```

## ۲) تصاویر مودهای بازی — کارت‌های اسلایدی صفحه‌ی اصلی

این‌ها همان کارت‌هایی هستند که در صفحه‌ی اصلی چپ و راست اسکرول می‌شوند.

|---------------|-----------|
| `mode-duel`   | دوئل یک‌به‌یک ⚔️ |
| `mode-ls`     | آخرین بازمانده 🛡️ |
| `mode-aon`    | همه یا هیچ 🤝 |
| `mode-league` | لیگ هفتگی 🏆 |
| `mode-record` | ثبت رکورد ⏱️ |
| `cup-crown`   | کاپی که بالای قابِ همه‌ی این کارت‌ها می‌نشیند |

```
sudo cp /home/ubuntu/mode-duel.png /var/www/prizequiz/mode-duel.png
```

```
sudo cp /home/ubuntu/mode-ls.png /var/www/prizequiz/mode-ls.png
```

```
sudo cp /home/ubuntu/mode-aon.png /var/www/prizequiz/mode-aon.png
```

```
sudo cp /home/ubuntu/mode-league.png /var/www/prizequiz/mode-league.png
```

```
sudo cp /home/ubuntu/mode-record.png /var/www/prizequiz/mode-record.png
```

```
sudo cp /home/ubuntu/cup-crown.png /var/www/prizequiz/cup-crown.png
```

## ۵) تصاویری که فایل نیستند

این‌ها **داخل خودِ `index.html`** ذخیره شده‌اند (base64) و با کپی فایل عوض
نمی‌شوند — برای تغییرشان باید فایل بازی دوباره ساخته و دیپلوی شود:

- تصویر اسپلش (صفحه‌ی بارگذاری اول)
- لوگوی برند و آیکن صورتک
- آیکن‌های سکه، کیف پول، قلب، جام، دسته‌بازی، گردونه، زنگوله
- تصاویر بلیط‌ها (سبز / آبی / قرمز)
- سه تصویر پس‌زمینه‌ی صفحه‌ی اصلی و صفحه‌ی طرح‌ها

---

## ۶) تصاویری که از پنل مدیریت آپلود می‌شوند

این‌ها را **کپی نکن** — از پنل (`pzadmin.html`) آپلود می‌شوند و سرور خودش نگهشان
می‌دارد:

- تصویر هر **موضوع** سؤال (در صفحه‌ی موضوعات، کارت ورودی و بالای سؤال دیده می‌شود)
- **بنرها**ی صفحه‌ی ورودی دوئل، ورودی آخرین بازمانده و تب بلیط فروشگاه
- **آواتار** بازیکن‌ها (خود کاربر آپلود می‌کند)
